## ✨ Features

- **🎨 Glassmorphic Design** — Frosted-glass cards and panels with `backdrop-filter: blur` throughout
- **🌗 Buttery Smooth Dark / Light Mode** — One-click theme switching powered by React 18 `useTransition` + CSS custom properties, ensuring zero jank even with 20 active 3D WebGL canvases
- **📱 Fully Responsive** — Adaptive layouts for mobile (≤600px), tablet (600–900px), and desktop (900px+)
- **⚡ Framer Motion Animations** — Entrance animations, hover lift effects, and staggered reveals on scroll
- **🤖 Interactive 3D Robot (Contact Section)** — A Spline-powered 3D robot character that reacts to form interactions — it looks at you while you type, jumps when you send a message, and changes expressions/colors based on custom React UI controls
- **🎠 Swipeable Project Carousel** — Drag-to-navigate project showcase with auto-play, dot indicators, and loop support
- **🏆 Certification Gallery** — Scrollable card list with certificate image previews and one-click PDF access
- **💼 Timeline Experience Section** — Alternating timeline with company logo, role chips, and skill tags
- **📩 Working Contact Form** — EmailJS integration for direct in-browser email delivery
- **🧭 Smooth Scroll Navigation** — Sidebar / topbar nav with `scrollIntoView` for instant section jumps
- **🎬 Animated Loading Screen** — Custom CSS bouncing-ball preloader displayed from first byte load, themed to match the light mode palette
- **🪙 React Three Fiber Skill Coins** — 20 interactive 3D spinning coin models (GLB), each bearing a tech stack SVG logo rendered as a crisp WebGL texture

## 🤖 Interactive Robot Contact Section

The Contact section features a fully interactive 3D robot character powered by the [Spline](https://spline.design/) runtime and bridged to React via `@splinetool/react-spline`.

### How It Works

- **Mood State Machine** — A `mood` prop (`idle` → `hover` → `typing` → `sending` → `success` / `error`) drives the robot's animation state via `splineApp.emitEvent()`.
- **React UI Controls** — Color and emoji buttons are custom glassmorphic HTML overlays (not Spline objects), managed by React state with `useImperativeHandle` / `forwardRef` for a clean API between components.
- **Jump Animation** — When the user submits the form, a `mouseDown` Spline event triggers a "Jump Rotate" timeline animation. After the animation plays, `emitEventReverse` is called with a 1.5-second delay to gracefully reset the robot and unlock the listener for the next submission.
- **Twemoji Emojis** — Emoji buttons render high-quality Twitter Twemoji SVG assets via CDN, ensuring pixel-perfect, consistent rendering across all OSes and browsers.
- **Camera Control** — User zoom/pan/rotate is disabled (`enableZoom: false`, `enableRotate: false`) for a clean embedded experience. Zoom is set programmatically (`setZoom(0.50)` desktop / `0.18` mobile).

## 🪙 React Three Fiber Skill Coins

The Skills section renders 20 interactive 3D spinning coins using a shared WebGL canvas architecture.

### Architecture

- **One Global Canvas** — A single `<Canvas>` is mounted fixed to the viewport. Each coin uses `<View track={ref}>` (from `@react-three/drei`) to render its scene into its DOM element's bounding box — no 20 separate canvases.
- **Shared GLB Model** — The coin `.glb` mesh is loaded once and cached in a `Map`. Each tile clones the scene, avoiding redundant GPU uploads.
- **SVG → WebGL Texture** — Each tech icon SVG is decoded, alpha-trimmed, and composited onto a `THREE.CanvasTexture`. Applied to both the front and back face of each coin.
- **Mouse Tilt** — `useFrame` lerps the coin's X/Y rotation toward the pointer position on hover for a premium parallax feel.
- **Performance** — DPR capped at `[1, 1.5]`, R3F `performance={{ min: 0.5 }}` for auto-quality regression, and `React.memo` with a custom pointer comparator prevents re-renders during theme switches.

## 🎬 Animated Loading Screen

A custom CSS loading animation is embedded directly in `index.html` and displayed from the very first byte — before any JavaScript downloads.

- **Phase 1 (HTML):** The native HTML/CSS bouncing-ball loader is shown immediately while the React bundle downloads.
- **Phase 2 (React):** Once React hydrates, it renders the same loader component for a seamless visual handoff and holds it for **3.5 seconds** using `setTimeout`.
- **Theme:** Light mode palette — soft cyan (`#e0f7fa`) background, deep cyan (`#0097a7`) ball, slate gray (`#475569`) platforms.

## 🌗 Buttery Smooth Theme Toggling

Theme switching is optimized at multiple levels to keep 20 active WebGL canvases stutter-free:

| Technique | Effect |
|---|---|
| `React.useTransition` | Marks the theme state update as non-urgent; React defers the expensive re-render tree without blocking the main thread |
| `React.memo` on `CoinTile` | Prevents coin tiles from re-rendering unless their own props change |
| `memo` + custom comparator on `SkillCoinView` | Compares pointer `x`/`y` by **value** (not object reference) so Three.js views are skipped entirely during theme toggle |
| CSS custom properties (`--coin-bg`, `--coin-border`) | Coin container colors update via the browser's CSS engine — zero React re-renders, zero WebGL interruption |

## ⚙️ Local Development

### Prerequisites
- Node.js ≥ 18
- npm ≥ 9

### Setup

```bash
# 1. Clone the repository
git clone https://github.com/Subhapreet21/Portfolio-Website.git
cd Portfolio-Website

# 2. Install dependencies
npm install

# 3. Configure environment variables
cp .env.example .env
```

Edit `.env` with your EmailJS credentials:

```env
VITE_EMAILJS_SERVICE_ID=your_service_id
VITE_EMAILJS_TEMPLATE_ID=your_template_id
VITE_EMAILJS_PUBLIC_KEY=your_public_key
```

```bash
# 4. Start the development server
npm run dev

# 5. Build for production
npm run build

# 6. Preview the production build locally
npm run preview
```

## 🚀 Deployment

This project is deployed on **Vercel**. To deploy your own fork:

1. Push your code to GitHub
2. Import the repository on [vercel.com](https://vercel.com/)
3. Add your environment variables (`VITE_EMAILJS_*`) in the Vercel dashboard
4. Vercel will auto-detect the Vite framework and handle the build
